TidyMind - Privacy

Your data stays on this computer.

- No account and no sign-in.
- Your data is never sent anywhere. The only time TidyMind goes online is
  the update check described below, and you can turn it off.
- No tracking, no ads, no usage statistics.

Update check
When TidyMind starts, and about every few hours while it is running, it
asks api.github.com for the number of the latest TidyMind version. Only if a newer version exists and
you choose "Update now" does it download the installer from github.com
(GitHub may hand the download over to its own file servers). Nothing about
you, this computer or your data is sent: only what any web request
contains, which is your IP address and the program name "TidyMind/<version>"
as the user agent. No cookies, no account. GitHub's own privacy statement
applies to these requests.
Turn it off under Settings > Updates > Check for updates automatically.
"Check now" there asks once, only when you press it.

Where your data is stored
Your memories, projects, collections, notes, to-dos, reminders, pictures and
attached files are all kept in one folder:

  %LOCALAPPDATA%\TidyMind
  (usually C:\Users\<your name>\AppData\Local\TidyMind)

Settings > Backup & transfer > Open data folder shows it.

Reminders
Each reminder adds a task to Windows Task Scheduler named
TidyMind_Reminder_..., which starts TidyMind at the reminder's time.
When it's due, Windows shows its title and message as a notification and
keeps it in the notification center until you clear it.
Uninstalling TidyMind removes these tasks.

Backing up and moving data
Settings > Backup & transfer > Back up all data saves everything into one ZIP
file, wherever you choose. Restore from backup, on the same page, puts it back.
"Export for transfer..." (right-click a project, a collection or an item) saves
just that one into a .tidymind file, wherever you choose, to import on another
PC. TidyMind never sends these files anywhere.

Deleting your data
When you uninstall TidyMind, it asks whether to delete this folder too. The
answer is No unless you choose Yes. You can also delete the folder yourself at
any time while TidyMind is closed.
